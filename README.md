# Ecosystem-alpha

Frontend-приложение для управления каталогом продуктов. Позволяет просматривать товары, добавлять их в избранное, а также создавать и удалять продукты.

## Демо

[Live Demo](https://zedf0r.github.io/EcosystemAlpha-test/)

## Технологии

- React 18
- TypeScript
- Vite
- React Router
- SCSS Modules
- Redux Toolkit
- Axios

## Установка

1. Склонировать репозиторий `https://github.com/zedf0r/EcosystemAlpha-test.git`
2. Перейти в каталог проекта и установить зависимости `npm i`
3. Команда для разработки `npm run dev`
4. Собрать сборку для продакшена `npm run build`
5. Запустить локальный сервер для просмотра сборки `npm run preview`
